# Fanos Tender brand guide

The lantern represents finding the right opportunity. The wordmark pairs bold “Fanos” with regular “Tender” so the product name stays easy to scan.

**Tagline:** Find the right tender.

| Color | Hex | Use |
| --- | --- | --- |
| Forest | `#1B4332` | Primary actions, the wordmark, and icon backgrounds |
| Ivory | `#FAF8F2` | Page backgrounds and the reversed logo |
| Ink | `#19241E` | Headings and body text |
| Amber | `#D99743` | The lantern flame on dark backgrounds and small accents |

Use Forest or Ink for text on Ivory. Use Ivory for text on Forest. On light backgrounds, the logo uses a deeper amber (`#A86422`) for the flame. Use clear labels alongside any color used to communicate a status.

Use the full wordmark in website headers and documents. Use the reversed wordmark on dark surfaces and the lantern by itself for app icons and favicons. Keep at least one flame-width of space around the mark. Below about 160 px of available width, consider using the icon with a separately rendered product label.

The wordmark uses Segoe UI with Arial as a fallback in the editable SVG. Use the supplied PNG when you need the exact appearance regardless of installed fonts. The existing web and Android typography can continue to serve the interface.

Keep product copy direct. Use phrases such as “Browse tenders,” “Save this tender,” and “View issuer instructions.”
